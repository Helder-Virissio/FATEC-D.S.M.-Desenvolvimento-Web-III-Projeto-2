Sobre o Curso

O curso superior de tecnologia em Desenvolvimento de Software Multiplataforma forma profissionais capazes de projetar, desenvolver e testar software para múltiplas plataformas, como web, mobile e desktop.

No 3º Semestre, o foco se volta para as práticas de gestão ágil, integrando front-end moderno, estruturação de banco de dados não relacional e conceitos sólidos de interface e experiência do usuário.
