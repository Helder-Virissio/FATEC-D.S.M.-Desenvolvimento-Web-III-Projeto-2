# FATEC D.S.M. — Desenvolvimento Web III — Projeto 2

## 🎯 Sobre o Projeto

O projeto centraliza as informações do semestre em um único site: cada disciplina tem sua própria página com professor responsável, dia/horário de aula, uma descrição da ementa e os principais conteúdos abordados. O rodapé de todas as páginas exibe os dados do aluno, carregados dinamicamente de um arquivo JSON.

## ▶️ Como Executar

```bash
git clone [https://github.com/Helder-Virissio/FATEC-D.S.M.-Desenvolvimento-Web-III-Projeto-2.git]
cd FATEC-D.S.M.-Desenvolvimento-Web-III-Projeto-2
node app.js
```

O servidor sobe em `http://localhost:3000/`.
